# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/), including its standards, scope, enforcement responsibilities, and enforcement guidelines. Be respectful, constructive, and inclusive; harassment and discrimination are not acceptable.

Report conduct concerns to the project maintainers. For sensitive reports, use the same private channel already documented in the [security policy](SECURITY.md): [GitHub Security Advisories](https://github.com/imwyvern/agent-guard/security/advisories/new). Non-sensitive process questions may be raised in a GitHub issue. Do not post sensitive reports in public issues or pull requests. The maintainers will review reports promptly and fairly, respect reporter privacy, and apply the Covenant's enforcement guidelines.
