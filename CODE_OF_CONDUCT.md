# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/), including its standards, scope, enforcement responsibilities, and enforcement guidelines. Be respectful, constructive, and inclusive; harassment and discrimination are not acceptable.

Report conduct concerns privately to the repository maintainer, [@imwyvern](https://github.com/imwyvern), using a private contact method listed on their GitHub profile. Do not post sensitive reports in public issues. The maintainer will review reports promptly and fairly, respect reporter privacy, and apply the Covenant's enforcement guidelines.
